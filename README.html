🗺️ Картографический сервис регионов России

Микросервис для генерации карт России с заливкой регионов по федеральным округам и отметками посещённых городов.

📌 Общее описание

Сервис доступен в двух форматах:

  • PNG – одна карта (эндпоинт /map)
  • PDF – многостраничный отчёт (эндпоинт /report)

Написан на R с использованием Plumber, sf, ggplot2, деплоится на Render через Docker.

🧰 Требования (локальная разработка)

  • R (>= 4.6.1)
  • RStudio (рекомендуется)
  • Homebrew (macOS) или apt-get (Linux) для:
    • gdal, proj, geos, udunits – для sf
    • libsodium – для plumber
    • fonts-liberation / fonts-dejavu-core – для кириллицы в PDF

R-пакеты (устанавливаются автоматически):

install.packages(c(
  "plumber", "sf", "ggplot2", "jsonlite", "DBI", "RPostgres",
  "showtext", "sysfonts", "ggrepel", "rnaturalearth", "rnaturalearthhires"
))

Представление v_user_visited_regions_full

CREATE OR REPLACE VIEW vkotov_russian_city_bot.v_user_visited_regions_full AS
SELECT
  fur.user_id,
  u.first_name,
  u.last_name,
  fur.region_id,
  dr.name AS region_name_ru,
  dr.name_en AS region_name_en,
  dd.id AS district_id,
  dd.name AS district_name,
  fur.dt_begin,
  fur.dt_end
FROM vkotov_russian_city_bot.fact_user_region fur
JOIN vkotov_russian_city_bot.dim_region dr ON fur.region_id = dr.id
JOIN vkotov_russian_city_bot.dim_district dd ON dr.district_id = dd.id
LEFT JOIN vkotov_russian_city_bot.dim_user u ON fur.user_id = u.id
WHERE fur.dt_end IS NULL;

🚀 Использование API

PNG

curl -X POST https://maps-russia-service.onrender.com/map \
  -H "Content-Type: application/json" \
  -d @data/input/user_1_1.json \
  --output map.png

PDF

curl -L -k -X POST https://maps-russia-service.onrender.com/report \
  -H "Content-Type: application/json" \
  -d @data/input/user_2_full.json \
  --output report.pdf

🔧 Разработка и локальный запуск

1. Клонирование

git clone git@github.com:vmkotov/maps-russia-service.git
cd maps-russia-service

2. Установка системных зависимостей (macOS)

brew install gdal proj geos udunits libsodium

3. Установка R-пакетов

install.packages(c(
  "plumber", "sf", "ggplot2", "jsonlite", "DBI", "RPostgres",
  "showtext", "sysfonts", "ggrepel", "rnaturalearth", "rnaturalearthhires"
))

4. Создание RDS-файлов

Rscript scripts/setup.R

5. Запуск API локально

Rscript -e "plumber::plumb('scripts/api.R')$run(host='127.0.0.1', port=8000)"

6. Генерация JSON для пользователя

Rscript scripts/export_user_full_json.R 2

7. Локальная генерация PDF

Rscript scripts/generate_full_report_local.R data/input/user_2_full.json

🐳 Деплой на Render

  1. Создайте аккаунт на Render.
  2. Подключите GitHub-репозиторий.
  3. Создайте Web Service:
    • Environment: Docker
    • Dockerfile Path: Dockerfile
    • Port: 8000
  4. Нажмите Deploy.

🧑‍💻 Для разработчиков

Как добавить новый регион

  • Убедиться, что регион есть в combined_split.rds.
  • Добавить запись в dim_region и dim_district.
  • Обновить словарь name_en.
  • Пересоздать combined_split.rds.

Как изменить цвета округов

В api.R найти district_colors и заменить HEX-коды.

Как добавить новую реку или озеро

  • Загрузить полигон из Natural Earth.
  • Сохранить как RDS в data/rds/.
  • Добавить в load_data() и в слой ggplot.

🤖 Для ИИ-инструментов

Возможные улучшения

  • Производительность: кеширование, использование data.table, оптимизация ggplot.
  • Данные: загрузка регионов из GADM или OSM.
  • Визуализация: интерактивные карты (leaflet), поддержка SVG.
  • API: авторизация, rate limiting, поддержка GraphQL.

Пример запроса к ИИ

Вопрос: «Как изменить шрифт на карте на Arial?»
Ответ: В api.R заменить font_add("liberation", ...) на font_add("Arial", regular = "/path/to/arial.ttf") и указать family = "Arial" в элементах theme.
